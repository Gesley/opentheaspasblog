Educação

AI Engineer Academy

Uma faculdade online cruzada com documentação premium e livro técnico interativo. O aluno vê onde está, o que falta e o que já desbloqueou.

Roadmap.sh como inspiração de progressão Dark mode nativo Conteúdo incremental

O problema

Cursos de IA costumam ser landing pages com cards ou blogs soltos. Quem constrói sistemas precisa de trilha, pré-requisitos e um lugar que se sinta universidade — não funil de venda.

A solução

Dashboard do aluno, roadmap visual, módulos expansíveis, aulas no formato de docs técnicas, projetos, quizzes, glossário e busca. A grade segue a ementa: fundamentos → LLMs → prompt → APIs → RAG → MCP → agents → multi-agent → DevOps/gestão → arquitetura → fine-tuning → governança → capstone → carreira.

O que já existe

  • Arquitetura pronta para centenas de aulas sem reescrever o app.
  • Estados de progresso por aula, unidade, módulo e curso.
  • Experiência de leitura com callouts, código e índice lateral.
  • Build público de referência em ambiente Lovable.
